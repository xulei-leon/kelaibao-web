- 在中国大陆网络与微信内置浏览器中验证主转化路径。
- 所有强制门禁通过后才标记 Production Live；否则保留 Preview/BLOCKED。

## 5. 工作范围

### 5.1 工作包：生产配置与发布校验

目标：

- 阻止占位、测试或不安全配置被误发布。

实现任务清单：

- [ ] 先写发布校验失败测试，覆盖缺失主体、示例域名、HTTP endpoint、个人微信类型和 Preview 索引配置。
- [ ] 配置获批正式域名、托管、HTTPS 和公开环境变量；真实值不进入 Git。
- [ ] 替换为正式企业微信“联系我”二维码并记录轮换方法。
- [ ] 校验生产 endpoint 为 HTTPS，且隐私政策准确说明实际接收方、目的和保存方式。
- [ ] 建立不输出完整 endpoint、联系人或秘密的 `validate:release` 命令。
- [ ] Production 构建拒绝占位主体、示例域名、个人微信二维码和未审查内容状态。

测试要求：

- [ ] 发布校验器覆盖全部通过/阻塞条件且不打印敏感值。
- [ ] 生产构建扫描不包含示例值、测试二维码或 Preview robots。

### 5.2 工作包：外部与专业门禁证据

目标：

- 用可审计但脱敏的记录确认开发范围之外的强制门禁。

实现任务清单：

- [ ] 记录经营主体、域名、备案/登记状态与托管适用性的确认结论。
- [ ] 记录直销、保险、证券页面及 Privacy/Terms/Disclaimer 的专业审查结论和版本。
- [ ] 确认案例、Logo、评价和资质均未展示，或具备可追溯书面授权。
- [ ] 核查分析、日志和错误监控配置不会接收询盘字段。
- [ ] 文档只保存状态、日期、责任人角色和脱敏证据引用，不保存账户、密钥或个人资料。

测试要求：

- [ ] checklist 每个强制项具有 `PASS`、`BLOCKED` 或 `N/A + 理由`，不得留空后标记上线。

### 5.3 工作包：真实环境验证与回退

目标：

- 证明正式域名和主要咨询路径在目标环境可用，并具备安全回退方式。

实现任务清单：

- [ ] 在正式域名验证 HTTPS、路由、metadata、canonical、sitemap 和 robots。
- [ ] 在中国大陆网络、微信内置浏览器、常见手机和桌面浏览器验证页面与二维码。
- [ ] 使用受控虚构数据验证表单成功、失败与微信降级；证据中脱敏 endpoint 和联系人。
- [ ] 验证分析事件不包含请求正文或联系方式。
- [ ] 记录部署版本、验证时间、结果和剩余阻塞。
- [ ] 演练恢复上一可用静态版本；不得修改或删除英文站部署资源。

测试要求：

- [ ] 自动验证全部通过，人工生产检查和回退演练具有记录。
- [ ] 微信与表单至少一条主路径可用；两者同时不可用时停止推广并回退。

## 6. 验收标准

- 经营主体、域名/备案、托管、HTTPS、企业微信、endpoint 和政策均为真实获批配置。
- 职业与政策专业审查有版本化结论。
- 正式域名在大陆网络、微信内置浏览器、手机和桌面端可完成咨询路径。
- 发布校验、全量测试、构建输出、日志/分析检查和回退演练全部通过。
- 中文站的部署、配置和回退不影响英文站。
- 任一强制门禁未通过时状态为 Preview/BLOCKED，而非 Production Live。

## 7. 验证要求

项目声明/推断的验证命令：

- `pnpm test`
- `pnpm lint`
- `pnpm build`
- `pnpm validate:release`（本 Sprint 新增，使用获批生产配置）

专项验证：

- 正式域名、大陆网络、微信内置浏览器、企业微信二维码和 HTTPS endpoint 的受控人工检查。
- metadata、sitemap、robots、分析/日志隐私和回退演练。

## 8. 实施顺序

1. 收集并确认外部输入；缺失则记录 BLOCKED 并停止 Production 工作。
2. 写发布校验失败测试并实现 `validate:release`。
3. 注入生产配置、正式二维码和批准政策版本。
4. 完成外部门禁记录和全量自动验证。
5. 在真实目标环境执行主路径与回退演练。
6. 完成代码 review-confirm、最终验证、独立提交和 Production/Blocked 结论。

## 9. 风险控制

- 把外部审批误写为开发完成：门禁使用证据化 PASS/BLOCKED 状态，缺失即停止。
- 生产值泄露：值只存在批准的部署环境，日志与文档仅记录变量名和脱敏状态。
- 大陆访问不稳定：在真实网络和微信内置浏览器验证，失败则不推广并回退。
- 回退误伤英文站：中文站使用独立部署与显式版本，不操作英文站资源。
