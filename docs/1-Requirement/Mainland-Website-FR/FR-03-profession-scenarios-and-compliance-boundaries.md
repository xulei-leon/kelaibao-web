# FR-03 职业场景页与表达边界

- `FR-ID`: `FR-03`
- `标题`: 职业场景页与表达边界
- `所属阶段`: 阶段 1 - 核心获客体验
- `开发顺序`: 3
- `优先级`: P0
- `前置依赖`: `FR-01`、`FR-02`
- `涉及包`: `/for/direct-sales`、`/for/insurance`、`/for/securities`、职业内容配置
- `是否属于原型阶段`: 是
- `来源类型`: 新需求
- `原始 SRS 章节`: 2.3、3、5、6.4、9
- `相关 FR`: `FR-06`、`FR-08`

## 目标

为直销、保险和证券从业者提供可识别的独立场景说明，同时将职业资质、所属机构审核和禁止表达作为可测试产品边界。

## 背景与问题

三个职业共享个人专业形象服务方法，但面临不同表达风险。若只使用泛化页面，用户难以判断适配性，也容易把内容服务误解为产品宣传或专业建议。

## 影响范围

- 三个职业路由、职业内容模型和职业免责声明。
- 首页职业入口和职业页微信 CTA。
- 禁止用语与页面内容契约测试。

## 需求描述

1. 三个职业页面使用共同结构：适用问题、服务帮助、可交付内容、客户责任、禁止范围和微信 CTA。
2. 直销页禁止未经确认的产品功效、收入机会、团队收益、发展下线和快速致富表达。
3. 保险页禁止具体产品比较、投保建议、收益演示和替代持牌机构审核的表达。
4. 证券页禁止证券推荐、买卖时点、收益预测、投资组合和个性化投资建议。
5. 页面明确客户对从业资质、机构规则、素材真实性和最终发布内容负责。
6. 每页链接至通用免责声明，并提供微信咨询入口。
7. 职业内容通过集中配置维护，不允许页面内另写冲突口径。

## 高层要求

- SRS 与 FR 只定义产品边界，不替代法律或机构合规意见。
- 未经专业审查的职业页面只能用于内部预览。
- 不展示或暗示赛诺全网代表客户所属机构或监管机构。
- 不收集从业证书、客户名单或金融资料来证明资质。

## 输入

- `ProfessionDefinition` 配置。
- 经确认的职业场景文案与禁止表达清单。
- 通用免责声明链接和微信 CTA。

## 输出

- 三个独立职业场景页。
- 职业级限制声明和内容契约测试。

## 失败与降级

- 职业文案未通过专业审查时，生产构建或发布清单必须将对应页面标记为阻塞。
- 未知职业不动态生成页面，引导至通用服务页或联系页。

## 不纳入范围

- 金融或直销产品目录、个性化推荐和资质认证。
- 客户机构审批工作流。
- 新增其他职业的自动模板系统。

## 最小验证方式

- 运行内容契约、类型检查和生产构建。
- 检查三个固定路由、禁止用语、免责声明链接和 CTA。
- 记录上线前专业审查的人工验证结果。

## 验收要点

- 首页可到达三个职业页面。
- 每页明确适用场景、可提供服务、禁止范围和客户责任。
- 页面不存在对应职业的禁止表达。
- 未通过专业审查时不能被标记为正式生产就绪。

## 备注

未来新增职业必须更新 SRS、内容模型、政策文本、测试和专业审查范围，不得只复制现有页面。
