# FR-23 客来宝官网 V3.3 内容与媒体套餐

## 文档状态

- 状态：完成 / Local Code Ready / Production BLOCKED（产品负责人明确跳过 review-confirm，2026-09-14）
- 变更来源：`客来宝官网内容策划V3.3_定稿版.docx`
- 目标 Sprint：M5-03
- 适用项目：`products/kelaibao/`

## 目标

按产品负责人确认的 V3.3 定稿更新客来宝统一中文官网，使首页、核心工具、团队方案、媒体服务、媒体套餐和关于页面使用同一套公开口径，并为小程序媒体报价提供稳定的 `/media/packages` 链接。

## 范围

1. 更新主导航、页脚栏目和首页 SEO metadata。
2. 更新首页六个内容区块，保留现有视觉资产和五个痛点，精简四类工具卡。
3. 将 `/features` 收敛为五阶段路径、会员权益和小程序体验入口。
4. 仅更新 `/team` Banner，保留其余团队方案内容与锚点。
5. 更新 `/media` 叙事并删除两个指定旧区块。
6. 新增 `/media/packages`，公开四套咨询型媒体套餐。
7. 更新 `/about` 的定位、公司介绍、指标和企业文化。
8. 更新公开路由、metadata、sitemap、`llms.txt`、测试和宣传口径登记。

## 明确不做

- 不修改新闻/案例 CMS、后台、数据库、询盘 API、部署架构或小程序代码。
- 不实现账号、支付、结算、订单、发票、自动报价或会员后台。
- 不建立第二应用、独立媒体站、子域名或跨应用内容接口。
- 不添加 Product、Offer 或购买型结构化数据。

## 功能要求

### 全站外壳与发现

- 主导航固定为：首页、核心工具、团队方案、媒体服务、新闻动态、关于我们。
- Logo 描述保持“K-Link 一站式拓客工具系统”。页脚“直销团队方案”改为“团队方案”。
- 首页 Title、Description、Keywords 使用 V3.3 定稿；metadata 类型允许可选关键词。
- `/team` metadata 去除旧“直销团队”限定。
- `/media/packages` 必须具有独立 Title、Description、canonical、Open Graph 和 WebPage 结构化数据，并进入公开路由、sitemap 和 `llms.txt`。

### 首页

- Hero 使用“一站式拓客与团队数智化工具系统”、定稿副标、“先领10份发群资料”按钮和四行社群获客说明。
- 工具区只展示内容、展示、效率、团队四张卡；删除十项工具名称，用定稿短说明替代，保留视觉素材并链接 `/features`，不使用外层灰底。
- 轻社交系统标题改为“专为营销人，打造的轻社交经营系统”，副标改为“从被人看见，到被人信任，再到被人主动找到”；五个痛点原样保留。
- 展业效率、媒体服务和底部 CTA 使用 V3.3 定稿文案；媒体四个方块保持现状。
- 底部显示“0 隐私采集｜0 业务干预｜私域资产完全归你”。

### 核心工具与团队方案

- `/features` 删除十项工具长介绍，保留现有五阶段路径；新增定稿 H1/副标、小程序二维码、九项会员权益表和定稿收尾。
- 文档中的“5个卡片图保持”解释为当前五阶段路径，不继续渲染十项工具长图。
- `/team` 只替换 Banner 提示语、H1、副标、补充说明和按钮文案；其他内容和稳定锚点不变。

### 媒体服务与套餐

- `/media` Hero 改为“发一篇，能用很久”和定稿副标。
- 保留媒体背书、个人与团队、一站式发稿及百家媒体区块。
- 将长期影响力区替换为“为什么带团队的人需要媒体发稿”及三条定稿说明。
- 删除“从社交曝光到媒体背书的转变”和“核心价值”两个完整区块。
- 新增四套套餐入口并链接 `/media/packages`；底部 CTA 改为“开启你的媒体背书之路”。
- `/media/packages` 完整展示个人 IP 背书、团队招商、品牌与项目、线下活动热播四套方案的适用对象、用途、媒体组合、标准价和会员价，只提供企业微信咨询入口。

### 关于我们

- 使用 V3.3 的页面副标、四段公司介绍、三项指标和三项企业文化。
- 移除这些区域中的旧“直销”限定；安全、新闻、公司实景和联系方式保持不变。

## 宣传口径与授权

- 产品负责人确认 V3.3 定稿同时作为本次事实证明和公开使用授权。
- V3.3 涉及的效率、媒体覆盖与组合、`100+`、`10万+`、`100万+`、隐私、业务干预、归属、四套价格和 50% 补贴登记为 `approved`。
- 统一使用归档 DOCX 为 source/evidencePath，owner 和 reviewer 为“徐磊（产品负责人）”，as-of 为 2026-09-14。
- V3.3 派生的可变事实统一采用 90 天复核期，2026-12-13 到期；过期后 release validation 必须阻断生产。
- 本 FR 不解除正式域名、备案、二维码、云资源或其他既有 Production blocker。

## 验收标准

1. 六个目标页面的首响应 HTML 包含 V3.3 指定内容，指定旧模块和旧文案不再出现。
2. `/media/packages` 可直接访问、可被 sitemap/`llms.txt` 发现，并无任何支付或账号入口。
3. 首页关键词、各目标 canonical/Open Graph 和结构化数据契约通过。
4. claims 登记完整、未过期时通过；在 2026-12-13 后按预期失败。
5. `pnpm test && pnpm lint && pnpm build` 通过。
6. `/`、`/features`、`/team`、`/media`、`/media/packages`、`/about` 在 320、390、768、1440px 无横向溢出、截断或不可操作控件。
