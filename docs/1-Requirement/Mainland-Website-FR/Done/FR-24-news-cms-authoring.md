## 目标

让预创建管理员通过 HTML 源码编辑完成新闻图文编辑和发布，无需调用上传接口或查找媒体 ID。2026-10-07 用户明确要求删除可视化编辑及相关代码/测试；新闻与案例共享编辑器统一为 HTML 输入。复用已有 MySQL 与私有 OSS。

## 背景与问题

[核查设计](../../../2-Design/News-CMS-Assessment-and-Enhancement-Design.md) 已确认后台与存储存在，但正文是 HTML textarea，图片缺少上传界面，封面需要手填 ID。

## 影响范围

现有新闻/案例共享编辑器、浏览器图片上传、单媒体查询 API、MySQL/SQLite 媒体 repository、测试和使用手册。不新增表，不更改既有发布状态机。

## 需求描述

1. 正文仅使用带标签的 HTML textarea，直接编辑 sourceHtml；不提供可视化编辑、格式工具栏或模式切换，删除 Tiptap 直接依赖、可视化组件/校验代码和专用测试。粘贴 HTML 按原始字符串保留，不自动上传拖放图片。
2. 新建与编辑均直接显示 HTML 源码，旧内容加载不改写、不解析为活动 DOM；危险 HTML 不得在编辑页面执行或加载外部资源。预览继续经服务端净化和 sandbox，保存/发布继续沿用现有 sanitizer。
3. 正文/封面复用上传流程：校验 JPEG/PNG/WebP 与 10 MB → 计算 SHA-256 → presign → HTTPS PUT → confirm。使用现有鉴权、CSRF、意图过期/幂等与服务端校验规则。
4. 上传有进行/失败提示和有界超时；confirm 可对同一 intent 有界重试。失败保持正文，不插入未确认图片，不回显签名或供应商响应；签名参数仅存内存。
5. 正文图片需要替代文本；封面上传后自动绑定 ID，显示图片、尺寸和体积；刷新/重开仍可显示已绑定封面。新增仅鉴权的单媒体 GET，返回公开元数据，不返回凭据、pending 数据或完整数据库行。
6. 封面继续满足现有 1200×630、约 1.90:1、≤350 KB 与公开使用确认规则。上传与授权分开；用户显式确认公开使用后才能保存绑定。可移除封面绑定，不删除 OSS 文件。
7. 编辑需浏览器支持 Navigation API；不支持时明确提示并保持只读，确保历史导航不静默丢稿。未保存变更时禁止发布/下线等会重新载入内容的动作，提示先保存；离开提示，失败/冲突保留输入，编辑/上传/请求期间防止重复动作和响应覆盖较新输入。
8. 沿用管理员登录、列表、保存、发布、下线、重新发布、历史与 SSR。案例复用编辑能力但保留首次授权门禁。
9. 会话恢复固定为保留编辑页，在新标签页打开登录，回原页点击“重新连接会话”，重新获取 CSRF 后继续操作。每次变更操作读取当前 Session/CSRF，避免另一个标签页登录使缓存 token 失效；上传端发生错误时可重新连接，不依赖旧接口统一 400 的状态码判定。正文不进入 Web Storage。验收覆盖失效→新标签登录→重连→原稿保存成功。

## 高层要求

生产保持 ESA → FC → RDS MySQL + 私有 OSS，数据库只由服务器访问，云服务直接 HTTPS；SQLite 仅本地测试。保存/预览/发布均复用现有服务端 sanitizer。编辑器不是安全边界。不引入新应用、公众账号或通用 webservice。

## 输入

标题、摘要、正文、图片文件、替代文本、显式封面公开使用确认、expectedVersion。后台不输入或提交 slug；新建提示“链接将在保存草稿后自动生成”，保存后只读显示链接路径。旧 API 的显式 slug 输入仍按 FR-12 校验。

## 输出

既有内容 revision、OSS 确认文件与 MySQL 媒体记录；可操作图文后台与公开 SSR 新闻。

## 失败与降级

旧格式保留源码；OSS 不可用时纯文字流程可用，图片失败不得绑定；会话失效要求重新登录并保留当前输入；冲突不静默覆盖。不上报正文、文件、签名 URL 或凭据。不在本次上线真实云资源。

## 不纳入范围

图库、素材删除、裁剪/转码、批量导入、排期发布、附件、营销页 CMS、多管理员审批。真实云采购/凭据/备案/恢复门禁不因本地实现自动通过。

## 最小验证方式

上传 HTTP 契约、失败/重试、HTML 源码原样保留与危险 HTML、封面重开与授权、未保存保护、新闻/案例回归；全量 pnpm test、pnpm lint、pnpm build；320/390/768/1440px 浏览器实测；本地数据库新闻生命周期。真实 OSS 测试没有配置时明确记录未验证。

## 验收要点

直接输入 HTML、无需查 ID 完成图文操作；重开不丢稿/封面；草稿不改变公开版本；发布/下线状态与 SSR 正确；失败不丢输入、不泄露凭据；四视口无关键控件溢出。

## 2026-10-07 Slug 自动生成补充

新闻与案例共享编辑器移除 Slug 输入、必填/预览校验及可编辑状态。创建时服务端自动生成唯一编号，后续修改标题、下线、重新发布均保留链接。实施契约与文档评审见 `docs/3-Plan/cms-auto-slug.md` 和 `docs/4-Reviews/cms-auto-slug-review-confirm.md`。
