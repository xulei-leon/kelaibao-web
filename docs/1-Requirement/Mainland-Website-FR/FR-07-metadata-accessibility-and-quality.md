# FR-07 Metadata、可访问性与发布质量

- `FR-ID`: `FR-07`
- `标题`: Metadata、可访问性与发布质量
- `所属阶段`: 阶段 3 - 发布质量
- `开发顺序`: 7
- `优先级`: P1
- `前置依赖`: `FR-02`、`FR-03`、`FR-04`、`FR-05`、`FR-06`
- `涉及包`: metadata、sitemap、robots、分析、响应式、可访问性与质量测试
- `是否属于原型阶段`: 否
- `来源类型`: 设计补强
- `原始 SRS 章节`: 6.9、8、10、11
- `相关 FR`: `FR-08`、`FR-13`

## 目标

使代码管理的公开页面可被正确抓取、在移动端与微信内置浏览器中可用、满足基础可访问性，并通过自动化契约防止品牌、隐私和范围回归；新闻/案例 SSR 与 SEO/GEO 扩展由 `FR-13` 承接。

## 背景与问题

站点以移动端微信转化为主，但仍依赖搜索和网页访问。页面质量、匿名分析和职业内容边界需要统一验证，不能仅依赖视觉检查。

## 影响范围

- 页面 metadata、canonical、Open Graph、sitemap 和 robots。
- 导航、标题层级、键盘焦点、表单状态、二维码说明和响应式布局。
- 匿名分析事件及内容、隔离和构建输出测试。

## 需求描述

1. 每个公开路由具有唯一中文 title、description、canonical 和 Open Graph 信息。
2. sitemap 只包含实际公开页面，不包含占位、未授权案例或内部预览页面。
3. robots 允许抓取核心获客页，并按环境阻止受控预览被索引。
4. 核心文案由静态 HTML 输出，不依赖客户端脚本加载。
5. 320px 及以上视口无正文横向溢出，导航、CTA、二维码和表单可操作。
6. 保持语义标题、跳过链接、键盘焦点、表单 label、错误提示和 `aria-live` 状态。
7. 分析只采集必要的匿名页面和 CTA 事件，不采集询盘字段。
8. 自动化测试检查品牌、职业边界、禁止能力、政策链接、路由、metadata 和英文站隔离。

## 高层要求

- 不为分析引入个人级扫码或好友追踪。
- metadata 和结构化数据不得声称存在未授权案例、评价或效果。
- 可访问性降级不得阻断微信或表单咨询路径。
- 预览环境与生产环境的 robots 行为必须明确区分。

## 输入

- 公开路由清单和页面 metadata 内容。
- `NEXT_PUBLIC_SITE_URL` 与可选匿名分析 ID。
- 核心用户路径和 SRS 禁止范围。

## 输出

- metadata、sitemap、robots 和匿名分析能力。
- 响应式、可访问性、内容契约、路由和隔离测试。
- 发布质量检查结果。

## 失败与降级

- 分析未配置或加载失败：不影响页面和 CTA。
- 站点 URL 未配置或非法：生产构建失败并给出明确错误。
- 非生产部署默认阻止索引，避免预览内容进入搜索结果。

## 不纳入范围

- 付费 SEO 工具、用户画像、跨站追踪或行为回放。
- 自动无障碍认证或对所有辅助技术的保证。
- 性能监控中的个人身份采集。

## 最小验证方式

- 运行 `pnpm test && pnpm lint && pnpm build`。
- 检查构建输出、sitemap、robots、canonical 和核心 HTML。
- 在 320px、常见手机宽度和桌面宽度执行关键路径检查。
- 使用键盘完成导航、弹层和表单操作。

## 验收要点

- 所有公开路由 metadata 唯一且与赛诺全网定位一致。
- 预览与生产索引策略正确。
- 移动端、桌面端和键盘路径均可完成咨询转化。
- 分析与错误记录不含个人信息。
- 契约测试能阻止英文站内容、禁止能力和虚构证明进入构建。

## 备注

真实中国大陆网络和微信内置浏览器验证属于 `FR-08`；新闻/案例 JSON-LD、RSS 与 `llms.txt` 属于 `FR-13`。
