# FR-08 中国大陆生产配置与上线门禁

- `FR-ID`: `FR-08`
- `标题`: 中国大陆生产配置与上线门禁
- `所属阶段`: 阶段 4 - 正式上线
- `开发顺序`: 8
- `优先级`: P0
- `前置依赖`: `FR-01`～`FR-07`、`FR-09`～`FR-14`
- `涉及包`: ESA、FC、RDS、OSS、DirectMail 生产配置、部署说明、上线清单、专业审查记录和全量回归
- `是否属于原型阶段`: 否
- `来源类型`: 新需求
- `原始 SRS 章节`: 8、9、10、11.4、12
- `相关 FR`: `FR-03`～`FR-07`、`FR-09`～`FR-14`

## 目标

确认最新阿里云全栈方案具备中国大陆正式公开推广所需的主体、域名、备案、运行安全、微信、隐私、专业审查、恢复和质量条件。

## 背景与问题

代码可构建不代表可以正式推广。备案、数据处理、企业微信、职业表达和大陆网络可用性均依赖真实生产信息，不能由开发人员用占位值推断。

## 影响范围

- 生产域名、ESA、FC、RDS、OSS、DirectMail、HTTPS、日志和分析配置。
- 企业微信正式二维码和服务时间。
- 备案/登记状态、隐私与职业表达审查记录。
- 生产部署说明、发布清单、回退方法和全量验证。

## 需求描述

1. 确认经营主体、正式域名、网站备案及按实际情况需要的登记事项。
2. 使用已通过 M2-00 的 `ESA -> FC 全栈 Next.js -> RDS + 私有 OSS` 链路，且全部资源独立于英文站。
3. 配置正式企业微信“联系我”二维码并阻止个人测试二维码进入生产。
4. 确认 Privacy、Terms、Disclaimer 与真实数据流、主体和 endpoint 一致。
5. 保存直销、保险和证券页面的适用专业审查结论。
6. 确认页面不展示未经授权的案例、Logo、评价或资质。
7. 确认分析、日志和错误监控不接收询盘字段，询盘只由 `/api/inquiry` 调用 DirectMail 且不落库。
8. 在正式域名、真实大陆网络、移动浏览器和微信内置浏览器中完成关键路径检查。
9. 建立可执行的 FC 部署、数据库迁移、配置校验和回退说明；失败时恢复上一可用 FC 版本。
10. 完成 RDS 自动备份验证和至少一次恢复演练，确认 OSS 私有与 ESA 媒体分发。
11. 验证新闻/案例 SSR、`404/410`、JSON-LD、RSS、sitemap、`llms.txt` 与 60 秒缓存边界。
12. 门禁未全部满足时只能标记为内部测试或受控预览，不得标记 Production Live。

## 高层要求

- 只允许已批准的单管理员、RDS 与新闻/案例 CMS；不得引入公众账号、支付、CRM、小程序或英文站共享部署。
- 所有第三方集成直接使用 HTTPS，不使用通用 webservice。
- RDS、OSS、DirectMail、Session 等密钥不得进入浏览器公开变量、Git 或日志。
- 未验证结论必须保留为假设或阻塞项，不得伪造通过状态。

## 输入

- 经营主体、域名、备案/登记和托管信息。
- 正式企业微信二维码与服务时间。
- ESA/FC/RDS/OSS/DirectMail 生产配置、隐私处理说明和日志/分析配置。
- 专业审查与授权记录。

## 输出

- 可审计的上线清单和门禁结论。
- 生产配置、独立全栈部署和数据库恢复证据。
- 正式域名关键路径、构建和回归验证记录。
- 回退说明和 Production Live/Blocked 结论。

## 失败与降级

- 任一强制门禁缺失：停止正式发布，保留预览状态并记录阻塞项。
- DirectMail 不可用：微信入口仍可使用并记录故障；若微信也不可用则暂停推广。
- 新部署异常：恢复上一可用 FC 版本；数据库迁移异常停止发布，不删除生产数据。

## 不纳入范围

- 代办备案、法律意见、持牌机构审批或持续合规服务。
- 在线支付、公众账号、CRM、小程序、多管理员和通用页面 CMS。
- 英文站部署迁移或基础设施统一。

## 最小验证方式

- 运行 `pnpm test && pnpm lint && pnpm build` 及全部内容契约测试。
- 在正式域名验证 HTTPS、路由、SSR、metadata、JSON-LD、robots、企业微信和 DirectMail 降级。
- 在中国大陆网络、微信内置浏览器、常见手机和桌面浏览器执行主路径。
- 核对备案/登记、专业审查、授权、隐私处理、RDS 恢复和 FC 回退清单。

## 验收要点

- 所有上线门禁均有真实证据和明确结论。
- 正式环境使用企业微信二维码、同域 HTTPS API、DirectMail 和正确政策文本。
- 大陆网络与微信内置浏览器可以完成微信或表单咨询路径。
- 任何日志和分析系统均不接收个人询盘内容。
- 中文站部署、数据库、域名和回退均不影响英文站。
- 门禁不完整时状态保持 Preview/Blocked，而非 Production Live。

## 备注

本 FR 是正式推广门禁，不把外部审批结果描述为开发团队可以保证的交付物。
