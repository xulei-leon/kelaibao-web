# FR-06 政策、隐私与效果声明边界

- `FR-ID`: `FR-06`
- `标题`: 政策、隐私与效果声明边界
- `所属阶段`: 阶段 3 - 信任与政策
- `开发顺序`: 6
- `优先级`: P0
- `前置依赖`: `FR-02`、`FR-03`、`FR-05`
- `涉及包`: `/privacy`、`/terms`、`/disclaimer`、全局声明和表单同意文案
- `是否属于原型阶段`: 否
- `来源类型`: 新需求
- `原始 SRS 章节`: 2.3、4.2、6.8、9、10、12
- `相关 FR`: `FR-03`、`FR-05`、`FR-08`

## 目标

公开与实际服务和数据处理一致的政策页面，并以真实表达、清晰合作、尊重授权和合理成果预期建立统一、可读的合作边界。

## 背景与问题

赛诺全网覆盖直销、保险和证券从业者且收集最小联系信息。政策不能只作为页脚模板，必须约束销售文案、表单同意和正式上线条件。

## 影响范围

- Privacy、Terms、Disclaimer 页面。
- 首页、服务页、职业页、联系页和页脚的简明声明及链接。
- 客户案例、Logo、评价和资质授权规则。
- 政策内容契约测试与专业审查记录。

## 需求描述

1. `/privacy` 说明实际收集字段、目的、接收 endpoint、共享范围、保存期限和用户权利。
2. `/terms` 说明人工适配、定制范围、人工报价、站外合同与付款、第三方平台依赖和客户责任。
3. `/disclaimer` 对外名称为“合作与使用说明”，以真实表达、清晰合作、尊重授权和长期价值四项品牌承诺说明合作原则，不再按职业逐项罗列免责条款。
4. 表单隐私同意必须链接至当前生效的隐私政策。
5. 全站不得把通用教育内容表述为针对访问者的保险、证券、投资或法律意见。
6. 客户信息、评价、Logo、资质或案例公开前必须具备可追溯的适当授权，并以正向合作承诺表达该要求。
7. 页面以合理预期说明成果会受到业务基础、投入程度、执行节奏、市场变化和平台环境等因素影响，不作确定结果承诺。
8. 正式上线前由适合当前业务范围的专业人员审查，文档保存版本和审查结论。

## 高层要求

- 政策内容必须反映真实配置，不能复制与产品无关的通用模板。
- SRS、FR 和产品文案不替代法律或持牌机构意见。
- 未确认主体、联系方式、endpoint 或保存政策时不得填写虚构信息。
- 声明必须可读，不得只隐藏在页脚或使用难以阅读的小字号。

## 输入

- 实际经营主体、联系方式和生产 endpoint 数据处理信息。
- 职业页面与表单字段。
- 授权记录要求和专业审查结论。

## 输出

- 三个公开政策页面，显示名分别为“信息与隐私说明”“合作服务说明”“合作与使用说明”，URL 继续使用 `/privacy`、`/terms`、`/disclaimer`。
- 全站统一的合作原则摘要与政策链接。
- 表单同意文本和内容契约测试。

## 失败与降级

- 主体、数据处理或审查信息未确认：标记为生产阻塞，不发布占位或猜测文本。
- 政策链接不可用：备用表单不得提交，页面仍保留企业微信入口及必要提示。

## 不纳入范围

- 法律意见、客户机构审批系统或资质认证。
- 在线合同、电子签名、支付和退款处理。
- 未获授权的案例管理系统。

## 最小验证方式

- 内容契约检查所有政策页面、页脚链接、表单同意和禁止承诺。
- 手工核对页面内容与生产配置、数据流和审查结论一致。
- 运行 `pnpm test && pnpm lint && pnpm build`。

## 验收要点

- 三个政策页面以批准的显示名公开访问，原 URL 保持不变且相互口径一致。
- 表单同意链接有效，未同意时不能提交。
- 核心销售页面展示适当的合作原则摘要。
- 未经授权的案例、Logo、评价和资质不会进入页面或 metadata。
- 专业审查未完成时不能标记为生产就绪。

## 备注

具体法律文本与保存期限必须在生产配置确认后完成，不由实现人员自行推断。
