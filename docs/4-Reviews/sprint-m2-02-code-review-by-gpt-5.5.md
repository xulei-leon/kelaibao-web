## Additional Notes

- The implementation does a good amount of local contract work for the single-admin model: server-only Argon2id, hashed session/CSRF tokens, row-locked known-admin login updates, disabled-admin session rejection, metadata-limited audit events, sanitizer allowlisting, sandbox preview, and direct HTTPS OSS provider boundaries.
- The current tests are useful but often assert source-code patterns or happy-path fakes. The highest-risk gaps need behavioral tests that model MySQL DDL retry, concurrent media confirmation, OSS copy/delete partial failure, object replacement during confirm, and multi-tab CSRF rotation.
- Local mock/fixture results should remain labeled `LOCAL_PASS` only. Real OSS private bucket behavior, STS expiry/overreach, ESA assets distribution, WAF/rate limits, and same-domain FC cookie behavior remain deferred under `M2-LEGACY-01`.
