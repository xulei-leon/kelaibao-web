# Sprint M5-06 代码 Review Confirm

日期：2026-10-21。方式：实施者源码、HTTP 与浏览器复核，不声称独立评审。范围：FR-26 运营原型改版。

| 发现 | 决策与结果 |
| --- | --- |
| 原型 HTML 的本地路径、移动换图脚本不可直接进入 Next.js | 已映射原应用路由，以服务端 React 标记和 picture 实现；仅复用既有二维码与菜单客户端边界。 |
| 静态文章原型重复配图、缺少日期、包含与现有清单不同的链接 | 五篇正文转为受控文本/图片块，去重配图，采用明确记录的本站导入日期；列表、详情和发现文件共用 FR-25 清单。未将原型误作旧 CMS 迁移证据。 |
| 原型 article meta description 截断在半句话，作为可见摘要过长 | 改用原型新闻列表中对应的完整短摘要，正文不截断；metadata 与发现摘要同步更新。 |
| 原型占位内容、到访页自链接、冲突用户人数 | 去掉尚未交付的视频/案例占位；复用办公室与到访灯箱；统一为 10000+，保留真实性待核实状态。 |
| 套餐补贴基数矛盾 | 标准价、特供价和会员价均保留，50% 对应特供价；没有官网购买、结算或支付。 |
| 团队/会员 CTA 不应打开媒体标题弹窗 | 按原型进入 `/about#contact`；媒体 CTA 保留原企业微信弹窗。 |
| Pages Router 新闻页缺图标声明导致 favicon.ico 404 | `_document.tsx` 显式引用现有 `/icon.svg`。 |
| 原型 shell 自动外边距及旧 Header 最小高度影响手机布局 | Hero 的垂直 margin 归零；手机 Header 高度与最小高度统一为 64px，菜单顶部同步。 |
| 旧 CMS 生成类型残留导致 tsc 引用已删除文件 | 仅清理 `.next/types` 与 `.next-dev/types` 缓存后重建；未恢复已退场 CMS。 |
| 新原型的规模、评价、投资与市场比价缺核验证据 | 增加四项 accepted-blocked claims；生产授权门禁仍 BLOCKED。 |

结论：实现决策符合本轮用户授权和工程边界；最终命令结果与四视口记录见 [验收证据](../5-Evidence/m5-06/README.md)。不涉及云部署、历史清库、生产授权或 Linux FC ZIP 验收。
