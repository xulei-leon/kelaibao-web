## 1. 使用规则与来源边界

### 1.1 规格优先级

1. 本文是 Excel `1.2` 的内容、模块顺序、列关系和素材映射依据。
2. [客来宝统一中文官网视觉设计规格](Kelaibao-Unified-Website-Visual-Design-Spec.md) 是颜色 Token、字体、Header、Footer、无障碍和交互行为的实现依据。
3. 两者出现差异时，保留本文的原始文案和模块顺序，使用统一视觉规格完成网页化；不得机械复刻 Excel 的宋体、纸张分页、细线框或二维码小尺寸。
4. 客来宝始终是唯一主品牌；K-Link 是产品名；公开导航使用“媒体中心”，路由保持 `/media`，客来宝媒体仍是站内子业务。

- Excel 原稿完整定义了 5 个页面的主体内容，但没有绘制可复用的全局 Header 和 Footer。

- 原稿中的括号说明，如“等有一些客户后插入”，属于编辑备注，不是公开页面文案。
- 本文中的 Markdown 列表替代了 Excel 文本框内的项目符号；文字内容不因此改变。

## 3. 全局页面框架

### 3.1 Header

- 桌面端为单行结构：左侧“客来宝”Wordmark，中部主导航，右侧“免费体验”按钮。
- Header 共享于所有页面；`/media` 不使用第二套 Logo、颜色或导航。
- 建议高度约 `72px`，内容与主体同宽；白色表面、底部分隔线、可选轻度 sticky。
- 当前页面必须有非颜色单一依赖的状态，如字重加下划线。
- 移动端使用菜单按钮；所有触控目标至少 `44×44px`。
- “免费体验”打开小程序 Dialog；“咨询客来宝媒体”只出现在媒体业务上下文并打开企业微信 Dialog。

### 3.2 Hero

- Hero 占页面第一个完整内容区，宽度与主容器一致。
- 首页原稿为约 `624pt × 305pt` 的宽区块，标题和说明集中在上半部，问题陈述位于下部；原稿没有右侧实图。
- 团队、媒体和关于页使用满宽文本 Hero；核心功能页以五阶段经营链作为首屏主视觉。
- 网页化后允许在 Hero 中使用已授权产品结构图或真实截图，但不得挤压、替换或改写原始标题和说明。
- 移动端标题、说明、CTA、视觉按此顺序单列；主 CTA 必须在首屏或一次短滚动内出现。

### 3.3 内容区

- 原稿基础画布宽约 `624–640pt`，页面由多个独立全宽框纵向堆叠。
- 网页使用最大内容宽度约 `1200px` 的 12 列栅格，保留原稿的“全宽章节 + 内部多列”关系。
- 默认章节间距：桌面 `80–120px`，移动端 `56–80px`。
- 原稿大量使用细蓝描边标注章节边界。网页中应转译为背景切换、留白、分隔线或轻卡片，不需要给每个章节画完整外框。
- 原稿图片占位块统一为中蓝色矩形；上线时必须替换成真实、获授权且与文案对应的素材，或使用诚实标注的结构示意。

### 3.4 Footer

Excel 未绘制 Footer。项目实现使用统一深蓝 Footer，至少包含：

- 客来宝主品牌与一句简短说明；
- 首页、核心功能、团队解决方案、客来宝媒体、新闻动态、关于我们；
- 联系入口和政策链接；
- “免费体验”作为产品动作，普通联系作为次级动作；
- 不放公众登录、价格、支付、未经确认的合作 Logo、统计数据或备案信息。

## 4. 栅格、视觉与组件系统

### 4.1 原稿视觉证据

| 类型 | 原稿表现 | 网页转译 |
| --- | --- | --- |
| 页面背景 | 大面积白色 | 使用 `canvas` 与 `surface` 形成轻层级 |
| 主描边 | `#2E54A1` | 对应品牌结构线或章节分隔，不整页框线化 |
| 深蓝箭头/图标 | `#1E386B` | 对应 `brand` 或线性图标 |
| 图片占位 | `#4874CB` | 替换为真实素材；缺失时使用明确的结构示意 |

| 场景 | 桌面 | 平板 | 移动 |

### 4.4 图片与素材规则

1. 产品功能页的蓝色竖向占位块约为 `3:5`，对应手机界面、功能截图或垂直插图。
2. 首页“四大模块”和“媒体传播中心”的蓝色块更接近横向/方形卡面，可使用统一比例的真实功能图或线性示意。
3. 团队与媒体页未提供人物照片；不得自行生成或使用暗示真实客户的虚构人物、证言或团队场景。
4. 关于页的“办公室场景 + 到访指引”必须使用真实、获授权照片和准确地址信息。
5. 合作伙伴 Logo、客户案例和新闻媒体 Logo 在授权前不得显示。
6. 二维码保留完整白边，不裁切、不加水印、不叠加装饰；网页有效显示尺寸不小于 `220×220px`。

| 核心功能 | `潜移模化` | 确认是否为“潜移默化” |
| 核心功能 | `私域营销（（持续曝光与私域引流）` | 删除重复左括号 |
| 媒体 | “一站式发稿服务”后的孤立 `` | 视为残留项目符号，不发布 |
| 关于 | `独立存储,由` | 确认中文逗号与空格 |
| 全站 | `IP`、`K-Link赋能体系` 等中英文间距 | 统一排版，不改变名称 |
