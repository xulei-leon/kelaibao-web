## 使用约束

- 最终实现逐字使用现有源码的用户可见文字，禁止复制图片中的生成文字。
- 禁止把图中的生成 Logo、指标、评价、客户、数据或未经实现的界面作为真实产品证据。
- 后续 fidelity QA 使用五张“当前基线”图片；两个初版只用于证明修订关系。
- 图片应与 FR-21 的内容、结构、路由和功能冻结契约一起使用，不能单独推导新页面或新组件。
